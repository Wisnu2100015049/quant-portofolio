# quant-portofolio
Proyek ini mengimplementasikan sistem perdagangan kuantitatif (quantitative trading pipeline) berbasis kecerdasan buatan untuk menyaring, memprediksi, dan mengoptimalkan portofolio saham. Strategi ini menggabungkan faktor Cross-Sectional Momentum & Price Action konvensional dengan pemodelan Tree-Based Machine Learning (RandomForestRegressor) untuk memprediksi forward return bulanan aset di Bursa Efek Indonesia (IHSG).Sistem ini dievaluasi menggunakan mekanisme pengujian kokoh berbasis Walk-Forward Validation (Rolling Window) guna mereplikasi skenario perdagangan riil secara akurat tanpa look-ahead bias.

🛠️ Alur & Metodologi Sistem
1. Pre-processing & Filter LikuiditasData Sourcing: Menarik data historis harga saham (OHLCV) secara massal via yfinance.Dynamic Liquidity Filter: Untuk menghindari manipulasi harga atau saham lapis ketiga yang tidak likuid, sistem menghitung rata-rata nilai transaksi harian selama 20 hari terakhir ($\text{Turnover} = \text{Close} \times \text{Volume}$). Hanya saham dengan rata-rata turnover di atas ambang batas (e.g., Rp10 Miliar/hari) yang lolos ke tahap pemodelan.

2. Feature Engineering (Momentum & Price Action Factors)Model dilatih menggunakan 3 fitur utama yang ditransformasikan secara cross-sectional per tanggal perdagangan:Factor Momentum ($T\text{-}12$ to $T\text{-}2$): Mengukur tren pengembalian jangka menengah dengan melewatkan rentang 1 bulan terakhir guna menghindari noise jangka pendek.Factor Reversal: Menangkap potensi pembalikan tren harga menggunakan performa jangka sangat pendek (1 bulan terakhir).Factor Lag Return (6-Month): Mengukur momentum akumulatif historis dari pergerakan harga 6 bulan ke belakang.

3. Pemodelan Machine Learning & Regularisasi PohonModel Core: Menggunakan algoritma RandomForestRegressor.Fitur Target: Variabel $R_{t+1}$ yang merepresentasikan tingkat keuntungan aset di satu bulan masa depan.Feature Scaling: Menggunakan StandardScaler secara berkala pada setiap jendela pelatihan untuk menyamakan skala varians antarfaktor.Regularization: Membatasi kompleksitas model pohon (max_depth=5, min_samples_leaf=10) untuk meminimalisasi risiko overfitting terhadap noise acak pasar saham.

4. Konstruksi Portofolio & Metode Pengujian (Backtesting)Mekanisme Rolling Window: Model dilatih menggunakan data historis (misal 10 tahun masa belajar), kemudian mengeksekusi prediksi untuk konstruksi portofolio di bulan berikutnya secara bergantian.Alokasi Aset: Saham diperingkat secara persentil berdasarkan hasil estimasi model. Sistem membangun beberapa klaster portofolio, seperti Top 10% (High Conviction), Top 30% (Balanced), hingga Top 50% (Broad Market) menggunakan pembobotan seragam (Equal Weighted).Friction & Cost Consideration: Perhitungan Net Return telah memperhitungkan biaya transaksi bulanan (trading fee & pajak) sebesar 0.2% per rebalancing.
